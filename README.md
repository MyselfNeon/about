### 🚀 *Deployment*
*This is a static website consisting of `index.html` and `styles.css` (and a `CNAME` file for custom domains). 
Simply host these files on any static web host like **[GitHub Pages](https://pages.github.com/), [Cloudflare Pages](https://pages.cloudflare.com/), or [Vercel](https://vercel.com/).** Ensure your `CNAME` file remains in the root directory if using a custom domain.*
